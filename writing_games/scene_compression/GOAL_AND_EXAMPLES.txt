Scene Compression — Goal and Examples Review

Review method
Vale → Skeptic → Professor → Continuity Auditor → Editor → Vale reconciliation.

Goal
The game teaches revision by compression. The learner should discover what a scene actually needs by rewriting the same event with progressively less space while preserving its essential effect.

How the mechanic meets the goal
Each exercise now pairs one event with one appropriate essential element. That element remains fixed through all three cuts:
1. DIRECTOR’S CUT — full treatment with action, reaction, and room to breathe;
2. TRAILER CUT — the same event in no more than three sentences;
3. POSTCARD CUT — the same event in one sentence.

The learner therefore changes only the available space while protecting the same required element. This creates a clean comparison: what disappears as the prose compresses, and what wording or image has to carry more weight because it must survive.

How the examples support the goal
The game now contains 30 curated event/essential-element pairs. The preservation target is chosen to fit the event rather than being randomized independently.

Examples include preserving the emotional turn from panic to relief when a child finds a parent; the cost of a missed winning shot; the relationship signal in a damaged borrowed item returned without explanation; the cause-and-effect link when an object falls onto train tracks; the practical consequence when a guest speaker is delayed; the failure of an expected fix when a repaired engine still makes the same noise; and the shrinking window for action when a ferry ramp begins to rise while a bag remains on the dock.

The examples cover emotional turns, causal links, relationship signals, physical evidence, decision points, practical consequences, realization, timing, uncertainty, and cost. That variety keeps the lesson about selection and emphasis rather than one narrow kind of prose.

Review
The previous comparison flaw has been removed. The “must survive” element no longer changes between cuts, and incompatible event/target combinations have been eliminated by using 30 curated pairs.

The exercise now isolates the intended variable: compression.

Verdict
PASS. The three-cut structure now directly teaches how to preserve an essential effect while reducing space.
