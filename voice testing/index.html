About this test

Kokoro has no dedicated child-age presets. Pitch-shifting isn't included in this first version, and a synthetic laugh may sound like spoken words instead. Audio is generated on your device; model and code assets are fetched from public hosts on first use. iOS may use more time and memory with WebAssembly. This is a mobile-friendly website, not a separately installed native iOS app.
