Core concept: character voice through perception

Character Filter

What you are learning: This game isolates one part of character voice: perception. What a character notices, compares, judges, values, and ignores can make neutral narration feel distinctly theirs. Controlled mode holds the perceptual move constant so the character filter is the variable you can actually compare.

Syntax, diction, rhythm, and broader prose style also contribute to voice; this exercise deliberately focuses on perception.
