Core concept: raising stakes

Escalation

Goal: Make a problem progressively harder in ways that increase cost, urgency, or consequence. Each escalation should make the character's existing goal harder—not simply add unrelated chaos.

Choose a scenario

Start by writing the basic problem.

How to play

Write a little after each escalation. Do not undo earlier events. Make the new pressure grow from what is already happening.

Each starting scenario has eight distinct five-step escalation plans. A plan is chosen from that scenario's own pool whenever a round starts.

Reflection: Did the scene become harder because the cost of failure increased, or only because more things happened?
