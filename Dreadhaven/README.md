# Dreadhaven

Survival-horror shelter-building game.

## Core direction

- Scavenge resources to upgrade existing shelters or build new ones.
- Fortify shelters against hordes, werewolves, ghosts, and other supernatural threats.
- Face both major events and dynamic, unpredictable attacks.
- Move disabled vehicles into position as barricades or defensive walls.
- Vehicles used as defenses can be damaged or destroyed during attacks.

Detailed mechanics, progression, and attack triggers remain to be designed.
