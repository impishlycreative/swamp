Core concept: causal plotting

Cause & Effect

Goal: Build a scene where each new event happens because of a previous action or decision. Avoid a string of unrelated “and then” events.

How to play

Write what the character does. Then reveal the next consequence card and make it a believable result of what has already happened. You may reinterpret details, but do not treat the new card as a random event dropping from nowhere.

Reflection: Can you connect each beat with “therefore” or “but”? If most links need “and then,” strengthen the causal connection.
