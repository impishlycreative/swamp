# First Person Game

This folder is reserved for development of a first-person game within the Swamp repository.

## Scope

Use this area for the game's first-person gameplay code, assets, level/scene data, experiments, and documentation without mixing them into the existing `writing_games` collection.

Suggested starting structure as the project grows:

- `index.html` — game entry point
- `css/` — game-specific styling
- `js/` — game logic, controls, player/camera systems
- `assets/` — images, audio, models, textures, and other media
- `levels/` — map/scene/level definitions
- `docs/` — design and technical notes
