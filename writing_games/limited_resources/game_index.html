Core concept: sacrifice & trade-offs

Limited Resources

Goal: Force meaningful choices by making useful options finite. Every resource you spend solves something now but leaves fewer choices later.

The game does not judge your prose. You click a resource whenever your scene uses it.

How to play

Write toward the goal. Spend resources only when the character genuinely uses them in the scene. Once a resource reaches zero, that option is gone.

Reflection: Which loss changed the character's strategy most? Did scarcity create a harder decision, or merely inconvenience them?
