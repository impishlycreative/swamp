Core concept: causal plotting

Cause & Effect

Goal: Build a scene where each new event happens because of a previous action or decision. Avoid a string of unrelated “and then” events.

Choose a starting scenario

How to play

Write what the character does. Then reveal the next consequence and make it a believable result of what has already happened. The consequence belongs to this scenario, but you still have to create the causal bridge from what your character actually did.

Reflection: Can you connect each beat with “therefore” or “but”? If most links need “and then,” strengthen the causal connection.
